# API REST

Documentacion interactiva:

`http://localhost:8000/api/v1/docs`

Endpoints principales:

- `GET /api/v1/health`
- `GET /api/v1/latest`
- `GET /api/v1/measurements`
- `GET /api/v1/measurements/raw/latest`
- `GET /api/v1/energy/summary`
- `GET /api/v1/energy/comparison`
- `GET /api/v1/energy/aggregates`
- `GET /api/v1/tariff`
- `PUT /api/v1/tariff`
- `GET /api/v1/annotations`
- `POST /api/v1/annotations`
- `PATCH /api/v1/annotations/{id}`
- `DELETE /api/v1/annotations/{id}`
- `GET /api/v1/devices`
- `GET /api/v1/events`
- `GET /api/v1/export/csv`
- `GET /api/v1/system/status`
- `POST /api/v1/backups/run`
- `GET /api/v1/backups`
